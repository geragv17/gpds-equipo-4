Problemática

Los estudiantes suelen tener dificultades para organizar sus actividades escolares, recordar las tareas pendientes y llevar un control de sus fechas de entrega. Esto puede provocar olvidos, retrasos y una mala administración del tiempo.

Por ello, se propone desarrollar un Sistema de Gestión de Tareas Escolares, que permita a los estudiantes registrar nuevas tareas, consultar las actividades pendientes, marcar tareas como completadas, eliminar tareas y consultar sus fechas de entrega.

El objetivo es ofrecer una herramienta sencilla que facilite la organización y el seguimiento de las responsabilidades académicas.

Acuerdos de trabajo

Como equipo, establecemos los siguientes acuerdos para mantener una buena organización durante el desarrollo del proyecto:

1. Comunicación constante: Todos los integrantes mantendremos comunicación para compartir avances, resolver dudas y reportar cualquier problema relacionado con el proyecto.
2. Responsabilidad y colaboración: Cada integrante cumplirá con las actividades que le sean asignadas y apoyará a los demás cuando sea necesario para alcanzar los objetivos del equipo.
3. Trabajo organizado y control de cambios: Utilizaremos GitHub para compartir el código, registrar los avances y revisar los cambios antes de integrarlos al proyecto, evitando modificaciones que puedan afectar el funcionamiento del sistema.
