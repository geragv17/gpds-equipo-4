
# EduTasks - Sistema de Gestión de Tareas Escolares

Proyecto desarrollado por el Equipo 4.

## Descripción
EduTasks es un sistema web que permite administrar
tareas escolares de manera sencilla.

## Funcionalidades
- Registrar tareas escolares.
- Validar nombre y fecha de entrega.
- Consultar tareas registradas.
- Marcar tareas como completadas.
- Regresar tareas al estado pendiente.
- Eliminar tareas con confirmación.
- Filtrar tareas por estado.
- Buscar tareas por nombre.
- Visualizar estadísticas de tareas.

## Tecnologías utilizadas
- PHP
- MySQL
- HTML
- CSS
- JavaScript
- XAMPP

## Instalación
1. Instalar XAMPP.
2. Copiar la carpeta SistemaTareasEscolares
   dentro de C:\xampp\htdocs.
3. Iniciar Apache y MySQL.
4. Entrar a http://localhost/phpmyadmin.
5. Crear una base de datos llamada tareas_escolares.
6. Importar el archivo tareas_escolares.sql.
7. Abrir en el navegador:
   http://localhost/SistemaTareasEscolares/

## Pruebas
Se realizaron 10 pruebas de validación:
- 4 pruebas del nombre de las tareas.
- 6 pruebas de la fecha de entrega.
